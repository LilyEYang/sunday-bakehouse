# Sunday Bakehouse
This project is an ordering system for Sunday Bakehouse. It includes a simple React application with a form for customers to place their orders.

## Project Structure
```
sunday-bakehouse
├── public
│   └── index.html
├── src
│   ├── components
│   │   └── OrderForm.tsx
│   ├── pages
│   │   └── Home.tsx
│   ├── App.tsx
│   └── index.tsx
├── package.json
├── tsconfig.json
└── README.md
```

## Features
- A homepage titled "Sunday Bakehouse"
- An order form with:
  - Input fields for name and phone number
  - A dropdown menu for selecting options

## Getting Started
1. Clone the repository.
2. Navigate to the project directory.
3. Run `npm install` to install dependencies.
4. Start the application with `npm start`.
